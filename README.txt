UNILIA ADMISSION RECORDS SYSTEM
================================

PROJECT CONTENTS
- index.html                    Homepage
- application-personal.html     Applicant personal details
- application-academic.html     Academic details and programme selection
- application-documents.html    Supporting document checklist
- application-complete.html     Application completion page
- status.html                   Application status page
- login.html                    Applicant login interface
- applicant-dashboard.html      Applicant dashboard
- style.css                     Shared stylesheet

IMPORTANT PROJECT NOTES
- This is a front-end prototype built with HTML and CSS only.
- The CSS declarations are written one per line.
- The pages are connected using ordinary HTML links.
- The login page does not authenticate users.
- The status and dashboard pages display sample records only.
